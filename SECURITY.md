# Security policy

Liftboard has no server and stores nothing outside your browser, so the most likely issues are
in the site itself: something that would let another origin read your data, a weakness in the
Content-Security-Policy, or a dependency with a known vulnerability.

## Reporting a vulnerability

Please report it privately through GitHub's
[private vulnerability reporting](https://github.com/AmriArshad/Liftboard/security/advisories/new)
rather than in a public issue. Include what you found and how to reproduce it. You'll get a
reply within a week.

Only the latest version, the one live at https://liftboard.amri.dev, is supported.
